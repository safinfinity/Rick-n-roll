2) CLASSIC BOARD REDESIGNED TO A TRUE 52-CELL LUDO CROSS
   (commits 76fc486 + 5b7963d)
----------------------------------------------------------
The old 48-square ring with 4 tokens/player is gone. Classic Mode now uses a
genuine Ludo cross board (15x15 grid) with 2 tokens per player.

src/game.h (constants + TokenState/Token comments):
  BOARD_SIZE            48 -> 52      (shared track cells)
  TOKENS_PER_PLAYER      4 -> 2
  SHARED_TRACK_STEPS    30 -> 52
  TOTAL_TRAVEL_STEPS    36 -> 58      (52 shared + 6 home)
  HOME_STEPS             6   (unchanged)
  POKEMON_POOL_SIZE      6   (unchanged)
  Token progress: 0 = base, 1..52 = shared track,
                  53..57 = home lane, 58 = goal.

src/board.c:
  - New geometry: LUDO_GRID 15, LUDO_CELL 44.0, LUDO_X 30.0, LUDO_Y 100.0.
  - path_r[] / path_c[] tables: the exact 52-cell shared path (sourced from
    the reference bocaletto-luca/Ludo implementation) plus ludo_pos() helper.
  - Start squares {1, 14, 40, 27}  (Red, Blue, Green, Yellow).
  - Safe squares = the 4 starts + 4 mid-sector stars {7, 20, 33, 46}.
  - classic_home_and_base() rewritten: per-player home lanes (Red row / Blue
    col / Green col / Yellow row) and 2 diagonal base spots per corner yard.
  - Removed the old ring helpers (ring_pos / ring_cell).
  - TEST_CLASSIC self-test updated - "test_classic: all assertions passed".

src/board.h:
  - Comments updated for the new geometry.

src/board_render.c:

    52 numbered shared squares, colored home lanes, base labels, and token
    drawing with a fanout offset so 2 tokens on one square are visible.
  - RING_* constants replaced with LUDO_*.
  - HUD now reads "Home: x/2".

src/main.c:

  - Game-over screen shows "Home x/2" per player.

src/pokemon.c / src/pokemon.h:
